Quorum is an incremental systems design game for software engineers. You grow a startup from one
server in a garage to a public company by fixing one bottleneck at a time. Each mechanic is based on
real system behavior: PHP-FPM workers wait on the database, a Node.js event loop stalls on bcrypt, and
a cache stampedes when it restarts.

## What makes it different

Most system design games ask you to pick the right answer. Quorum gives you a running system with
one bottleneck at a time. Every fix moves the bottleneck: a faster App Server sends more queries to
the Database, a Cache removes Database load and adds stale reads, and a Read Replica adds read
capacity and replication lag. The game teaches you which question to ask, not which product to buy.

The Simulation is deterministic and tested across Chromium, Firefox, WebKit, and workerd. The
[design document](/design) records every rule, and the [reality check](/design/reality-check) names
the real incident or paper behind it.
