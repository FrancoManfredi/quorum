Work through these steps in order. Each one points to the page that explains it, so you can read only the page you need.

![The speed buttons in the toolbar](/play/speed-controls.png)

1. **Found the Company.** Click **Founder**, choose **Start a company**, type a name and select **Found**. See [Start and found a Company](/play/start-a-company).
2. **Pause.** Press `Space`. Nothing changes while the clock stops, so read in peace. `S` changes the speed.
3. **Read the screen.** Find the HUD, the toolbar and the dock. See [The screen at a glance](/play/the-screen).
4. **Collect.** Click **Collect** on the Payments card, or press `C`. Do it about once a minute until you research Stripe Billing. See [Your first Company](/tutorials/first-company).
5. **Read a card.** Click the App Server and read its **Load** row. Amber means 70% and red means 90%. See [Read a Node card](/play/read-a-node-card) and [The Inspector](/play/the-inspector).
6. **Place a Component.** Open a build group, pick a part and click the board. See [Place Components](/play/place-components).
7. **Wire it.** Drag from the output port on a card's right edge to another card. See [Wire Nodes with Links](/play/wire-nodes).
8. **Fix the first limit.** The Garage box runs out of RAM or CPU credits. See [Your first bottleneck](/tutorials/first-bottleneck).
9. **Start a Study.** Press `R` once it shows and select **Start Study**. See [Research and Team panels](/play/research-and-team).
10. **Keep Mail in view.** The Inbox badge turns red when a message needs you. See [Mail, Dashboard, Glossary, pager, region tabs](/play/mail-dashboard-glossary).
11. **Meet an incident.** Fix the cause, then file the postmortem. See [Your first incident](/tutorials/first-incident).
12. **Learn the keys.** Press `H` for the short list, or read the [key reference](/play/settings-and-keys).

If you place the wrong thing, press `Z`. An undo inside the first half minute refunds the full price. See [Clock, undo, saves](/play/clock-undo-saves).

The Company saves itself, so close the tab whenever you like.
