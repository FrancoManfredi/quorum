# Accessibility checklist

The M9 exit check ([GDD 17](./gdd/17-scope-and-roadmap.md#milestones)). Items come from
[GDD 15 "Accessibility"](./gdd/15-ui-ux.md) plus the WCAG 2.2 AA items that apply to the panels.
Run it before a release: axe-core on the title screen, the lab with a panel open, and a Challenge,
then the keyboard-only run below.

| Item                            | Check                                                                                                                                                                                                                                                                            | State                                           |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| No serious axe violations       | axe-core (WCAG 2.0/2.1 A and AA, best practices) on the three screens                                                                                                                                                                                                            | Passes                                          |
| Status is not colour alone      | Node cards show a dot, triangle, square, or cross for ok, warn, danger, and down; a chip at low zoom keeps the same mark on its medallion                                                                                                                                        | Passes                                          |
| Text contrast                   | Status text at least 4.5:1 on wells and cards (`--ok`, `--danger` in `styles.css`)                                                                                                                                                                                               | Passes in light; dark not measured by axe       |
| Focus visible                   | Controls show a focus ring; the selected Node has a ring outside its card                                                                                                                                                                                                        | Passes                                          |
| Keyboard reach                  | Arrows select Nodes, Enter enters the Inspector and places a part in hand, `L` links, `Shift+T` and `Shift+F` tidy and fit, `Enter` confirms a Tradeoff; panel keys R, T, P, H, G; Space, S, Z, Shift+Z, U, Del, C, M; Tab reaches the Node list and the Dashboard's scroll area | Built; the keyboard-only run has not been rerun |
| Hidden content is not focusable | Closed build tray is `inert`                                                                                                                                                                                                                                                     | Passes                                          |
| Reduced motion                  | System setting or Settings › Reduce motion: packets hold still, still arrows carry each busy link's rate, the Bottleneck stops pulsing, panels appear at once                                                                                                                    | Passes                                          |
| Sound can be muted              | Settings › Mute sound, or `M`                                                                                                                                                                                                                                                    | Passes                                          |
| Text at 150%                    | Settings › Text at 150% scales the interface's type through `--type-scale`, so panels, rows, and the HUD keep their boxes; the Research tree grows its node boxes and spacing, and a long name wraps onto a second line                                                          | Passes                                          |
| Screen readers                  | A hidden Node list in board order, naming each Node's kind, size, and load, whose entries are buttons that open the Inspector                                                                                                                                                    | Passes                                          |
| Kind shapes                     | A packet shape per request kind: circle, square, triangle, or diamond, beside each kind's colour                                                                                                                                                                                 | Passes                                          |

Keyboard-only run: from the title, Tab to Continue and press Enter; press an arrow key to select the
first Node, arrows to move, Enter to reach the Inspector, Tab through its controls, Esc to return;
Tab into the Node list and press Enter to open a Node's Inspector; press G to open the Glossary and
type in its search; press M and turn on Text at 150%.
